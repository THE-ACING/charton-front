# Charton 🎵

**Charton** is a modern music streaming service built as a Telegram Mini App. With seamless integration, users can enjoy their favorite music without leaving the Telegram ecosystem.

## Features 🚀
- **Stream music** directly within Telegram.
- Modern and responsive UI using **Next.js**, **TypeScript**, and **TailwindCSS**.
- Backend powered by **Python** for robust and scalable performance.
- Easy-to-use SDK integration with `@telegram-apps/sdk-react`.

## Technologies Used 🛠️
- **Frontend**:
    - [Next.js](https://nextjs.org/)
    - [TypeScript](https://www.typescriptlang.org/)
    - [TailwindCSS](https://tailwindcss.com/)
    - [@telegram-apps/sdk-react](https://telegram-apps.dev/)
- **Backend**:
    - [Python](https://www.python.org/)
